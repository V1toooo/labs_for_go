# labs_for_go
Labs for GO extra course at SPbU

### #1 Окружение и первый Go-проект

1. Создать свой репозиторий, добавить в коллабораторы преподавателя (github.com/vacmannnn) и других кураторов. 
2. Создать Pull Request в ветку main в котором *минимум* должны быть:
    - go.mod
    - файл main.go
    - .gitignore
    
    ❗ **Название** PRa **обязано** включать в себя номер ДЗ. (напр. task 1/”Крутое название [1]”/Homework1/…)
    
3. В файле main.go должно быть решение задачи https://leetcode.com/problems/two-sum/description/: 
    - функция `twoSum(nums []int, target int) []int` с кодом решения
    - функция `main` , в которой вызывается twoSum с любыми аргументами
4. В описании Pull Request написать результат выполнения команд `go version` и `go env GOPATH` , например:
    
    ```shell
    ~/code/courses                                                         
    ❯ go version                                          
    go version go1.26.4 darwin/arm64
    
    ~/code/courses                                                                                                                                                                      
    ❯ go env GOPATH
    /Users/aleksandrlekomcev/go
    ```
    
### Критерии оценивания

6 баллов — Репозиторий создан, PR оформлен по всем правилам (название содержит номер ДЗ, добавлены go.mod, main.go, .gitignore). Функция twoSum работает для всех краевых случаев, код отформатирован gofmt, в описании PR указаны выводы команд. Коммиты информативные.

5 баллов — Все требования выполнены, но есть мелкие недочёты: например, в описании PR нет вывода go env GOPATH, или функция twoSum не обрабатывает случай с отрицательными числами, но основная логика верна.

4 балла — Репозиторий создан, PR есть, но отсутствует один из файлов (например, .gitignore) или функция twoSum работает только для частного случая (например, только для положительных чисел). Либо код не отформатирован, но компилируется.

3 балла — Репозиторий создан, но PR не соответствует требованиям (нет номера ДЗ в названии, нет описания). Функция twoSum содержит логические ошибки (не возвращает индексы или возвращает неверный результат). Либо отсутствует main или go.mod.

0–2 балла — Работа не сдана, скопирована, или репозиторий не содержит решения задачи twoSum. Либо PR не создан, либо код не компилируется. Структура ответа не соблюдена.

Отметка за задание снижается при более поздней сдаче задания (1 балл за каждые 2 недели опоздания).

Дедлайн: 1 неделя
